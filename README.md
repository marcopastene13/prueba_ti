# Base de datos (SQL Server)

1. Abrir SQL Server Management Studio u otra herramienta.
2. Ejecutar el archivo `database/schema.sql`.
3. Esto creará la base de datos `PruebaTiLibros` con las tablas `Usuarios` y `Favoritos`.

La aplicación backend asume por defecto:
- Servidor local: `localhost`
- Base de datos: `PruebaTiLibros`
